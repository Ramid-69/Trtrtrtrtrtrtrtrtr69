# Telebirr (React Rewrite)

A modern, responsive React application recreating the Telebirr Ethiopian Mobile Money & SuperApp client originally built with Flutter.

## Features Preserved

- **Telebirr Brand & Navigation**:
  - Ethio Telecom and Telebirr header branding.
  - User greeting (`Selam, BirukBr7`) and notifications icon with active badge count.
  - Language dropdown selector with Amharic, Oromo, Tigrinya, and Somali options.
  - Main balance with interactive show/hide toggle.
  - Sub-balances for Endekise and Rewards with toggleable visibility.
  - Arched yellow marquee strip with continuous announcement: *"ONE APP FOR ALL YOUR NEEDS!"*.

- **Top Services Grid**:
  - Send Money
  - Cash In/Out
  - Airtime/Packages (with +10% badge)
  - Request Money
  - Financial Service With Dashen Bank
  - Financial Service With Commercial Bank of Ethiopia (CBE)
  - Pay for Merchants
  - SuperApp directory

- **Promotional Carousel Slider**:
  - Auto-playing carousel with original campaign banner images.
  - Carousel dot indicator with active state tracking.

- **Transaction Details & History**:
  - Transaction details link with interactive drawer/modal showing full transaction history, filtering by Money In / Money Out, and status tags.

- **Bottom Services Grid**:
  - 33rd Christmas Trade Fair
  - Pay Ethio Telecom Bill
  - Schedule Payment
  - Transfer to Bank
  - Transfer to Wallet
  - Fuel Payment
  - Nearby Fuel Station
  - More Services

- **Scan QR Floating Action Button**:
  - Centered primary action button for instant QR code payment and merchant scanning.
  - Interactive camera viewfinder simulator with flash toggle and album photo support.

- **SuperApp Bottom Navigation**:
  - Home, Payment, Apps, and Account screens.

## Tech Stack

- **Framework**: React 18 with Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
